Photoka portable mode

While this file sits next to photoka.exe, Photoka keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PhotokaData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Photoka with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Photoka) instead.
If PhotokaData can't be written (for example on a read-only drive), Photoka says so and
uses %APPDATA%\Photoka instead.
